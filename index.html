一、博物館簡介

   

國家漫畫博物館（National Comic Museum，簡稱國漫館）位於臺中市西區林森路「臺中刑務所官舍群」，園區結合日治時期刑務所演武場與木造宿舍群，於 2023 年底展開開展體驗。這裡不只保存了珍貴的百年日式建築聚落，更是全臺灣首座以漫畫為主題的國家級博物館。

   

園區內最具代表性的建築為演武場主體與周邊日式木造官舍。這些建築見證了臺中近現代都市的演變，如今透過漫畫主題特展、跨界市集與文創體驗，打造出空間與當代視覺藝術對話的創新場所。

   

從日式庭園、榕樹樹屋到各式主題漫畫展覽，國家漫畫博物館就像是一本巨大且生動的實體漫畫書。本篇以景點整理與建議散步順序，介紹這座融合歷史古蹟與當代漫畫文化的熱門景點。

   

        園區地址：臺中市西區林森路 33 號。
        閱讀重點：日式建築群、臺漫歷史展覽與戶外光影藝術。    

   
       

二、園區特色與散步順序

   

值得留意的三個特色

   
           
  • 歷史建築：保存完整的日治時期刑務所演武場與典雅的日式木造官舍群。
    •        
  • 漫畫策展：多元且豐富的臺灣原創漫畫展覽、跨域藝術裝置與體驗空間。
    •        
  • 人文景觀：包含百年老榕樹樹屋、日式枯山水庭園與池塘綠意景觀。
    •    
   

建議散步順序

   

以下是本報導規劃的散步建議，您可以依方向彈性調整。

   
           
  1. 進入林森路主入口後，先參觀演武場主館，感受壯麗的日式道場空間與入口意象。
    2.        
  2. 漫步至大榕樹樹屋區，欣賞老樹與建築交織的自然景色並拍照留念。
    3.        
  3. 逐一探訪各棟木造官舍展館，觀賞臺灣原創漫畫專題展覽與限定主題快閃店。
    4.        
  4. 前往鏡池與周邊休憩區散步，最後可以在主題咖啡館或文創賣店整理今日的心得。
    5.
